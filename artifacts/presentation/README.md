# Veilo presentation

- `Veilo.key`: native Keynote version for macOS.
- `Veilo.pptx`: PowerPoint version with the same slides and spoken presenter notes.
- `../../docs/presentation/speaker-notes.json`: the twelve spoken scripts, in slide order.
- `../../slide_deck.md`: slide content, references, evidence links and review context.

In Keynote, choose **View → Show Presenter Notes**. Notes contain only the words to say, with no source dumps, Markdown headings or visual-production instructions. The script is approximately 870 words; allow about seven to eight minutes with pauses and technical explanations. The website demo is separate.

The deck uses Inter and Space Grotesk. Both fonts are installed on the author's Mac; install those families on another presentation machine to retain the intended typography.

The two flat technical diagrams are retained under `diagrams/`. Their built-in ImageGen prompts are recorded in `imagegen-prompts.md`. Other illustrations and the road artwork are embedded in the decks. These are explanatory illustrations, while the execution slide uses captured Explorer receipts with clickable transaction links.

The evidence is historical Solana devnet execution, not a claim of a fully unattended private-funded marketplace hire. Pricing and the five-year direction remain proposals. Current subscription billing is unimplemented and the marketplace fee is zero. Technical references and proof-setup limitations are in the canonical slide source and project security documentation.
