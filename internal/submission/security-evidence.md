# Security evidence

The maintained public source is [docs/security/evidence.md](../../docs/security/evidence.md). [Current status](../../docs/guide/status.md) records evidence/environment limits; [the demo checklist](../../docs/guide/demo.md) owns outstanding signatures and screenshots. Do not maintain a second assessment or pass/fail register here.

This internal path is not an access-control boundary: tracked files can be public. Keep reviewer deliberations, organizer correspondence, private prompts, raw logs, credentials and encrypted backups outside published source. The owner must decide which submission notes and sanitized outputs may be released; see [handoff](../../docs/handoff.md).
